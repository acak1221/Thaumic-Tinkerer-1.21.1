Thaumic Tinkerer добавляет в Thaumcraft 4 устройства для поздней игры, набалдашники, зачарования и ветку KAMI. Этот репозиторий —
его порт на Minecraft 1.21.1.

> [!IMPORTANT]
> Это **аддон**, а не самостоятельный мод. Ему нужен **[Thaumcraft 4 Reload](https://github.com/acak1221/Thaumcraft-1.21.1)** —
> порт Thaumcraft 4.2.3.5 от Azanor на Minecraft 1.21.1. Без него аддон ничего не делает. Исследования аддона лежат на отдельной
> вкладке Таумономикона и опираются на исследования Thaumcraft.

## Что внутри

Содержимое то же, что в моде для 1.7.10: 74 исследования и 127 рецептов, сверенные с исходником оригинала поле за полем
([docs/PARITY_REPORT.md](docs/PARITY_REPORT.md)).

| Группа | Содержимое |
|---|---|
| **Устройства** | Осмотический стол зачарований (зачарования выбираешь сам, вис платит жезл), Трансвектор и Трансвекторный дислокатор, Динамическая дощечка, Таум-восстановитель, Воронка для эссенции, Кинетический и Материальный притяжатели, Удалённый установщик, Аспектализатор, Пьедестал некроманта, Эфирная платформа, Левитатор, Голем-соединитель |
| **Набалдашники** | Искажение, Перемещение, Вмешательство Края, Подъём, Лечение, Телекинез, Пламя ифрита, Небесное вмешательство, Теневой луч, Высасывание опыта |
| **Зачарования** | Четырнадцать, их даёт только Осмотический стол: Прыгучесть, Замедленное падение, Наскок, Ударная волна, Огненное прикосновение, Разрушение, Осколочность, Туннель, Быстрая стрельба, Вампиризм, Храбрость, Направленный удар, Удар по площади, Добивающий удар |
| **Предметы** | Ткань поглощения заклинаний, Шлем открытия, Проклятое лезвие духа, Кольцо черной дыры, Кошачий амулет, Талисман очищения, Том записи исследований, Гиперэнергетический нитор, Светящийся газ и Газ темноты, Наполненные семена и Пропитанная пашня, шесть видов пропитанного огня |
| **KAMI** | Ихор, Ихоровая ткань и Ихорий; ихоровая броня и четыре её пробуждённые части; ихориевые инструменты и их пробуждённые версии; Бездонная сумка, Ихориевый наконечник и Ихорный серебродревесный стержень; Небесный портал, Терраформинговое стекло, Протоглина, Админиум-портал и его измерение. Ветка отключается настройкой |
| **Строительные блоки** | Закоптившийся кварц и блоки из него, плиты и ступени из брусчатки Thaumcraft |

Необязательные интеграции, работают только при установленном моде: страницы рецептов для **EMI** и **JEI**, подсказки блоков для
**Jade** и энергия через Трансвектор (на NeoForge — его собственная энергетическая capability, на Fabric — через **Team Reborn Energy**).

Не перенесено: периферия ComputerCraft и OpenComputers и EU из IC2. Все отличия от мода для 1.7.10 перечислены в
[docs/DEVIATIONS.md](docs/DEVIATIONS.md).

## Установка

1. Поставь **Thaumcraft 4 Reload** для своего загрузчика из его [релизов](https://github.com/acak1221/Thaumcraft-1.21.1/releases)
   и всё, что ему нужно (список в его [README](https://github.com/acak1221/Thaumcraft-1.21.1#installation)).
2. Скачай jar Thaumic Tinkerer для того же загрузчика из [релизов](https://github.com/acak1221/Thaumic-Tinkerer-1.21.1/releases)
   этого репозитория и положи в `mods/` рядом с Thaumcraft.

| | Fabric | NeoForge |
|---|---|---|
| Jar аддона | `ThaumicTinkerer-fabric-<версия>.jar` | `ThaumicTinkerer-neoforge-<версия>.jar` |
| Minecraft | 1.21.1 | 1.21.1 |
| Thaumcraft 4 Reload | jar для Fabric | jar для NeoForge |
| Ещё нужны | Fabric API, Architectury API 13.0.11+ | NeoForge 21.1.259+, Architectury API 13.0.11+ |

**Какая версия Thaumcraft.** Аддон пользуется только публичным `thaumcraft.api`, и ему нужны расширения, которые есть в Thaumcraft 4
Reload с 2026-10-31. Каждый релиз называет сборку Thaumcraft, с которой он проверен, в своём `BUILD_INFO.json`: 0.1.0-alpha.7 собран и
проверен с Thaumcraft 4 Reload 0.1.0-alpha.11. С 0.1.0-alpha.24 он тоже запускается, но наборы тестов на этой паре не прогонялись.

Играй в новом мире или с резервной копией: оба мода в альфа-версии.

## Состояние

**Альфа** (0.1.0-alpha.7). Все восемь групп содержимого перенесены для обоих загрузчиков из общей кодовой базы.

- Релизная сборка 0.1.0-alpha.7 прогнала 429 JUnit-тестов, 362 GameTest на сервере Fabric и 371 на сервере NeoForge, без единого падения.
- Клиент осмотрен в клиенте разработки на обоих загрузчиках, мультиплеер — на выделенном сервере с настоящими клиентами
  ([docs/CLIENT_VERIFICATION.md](docs/CLIENT_VERIFICATION.md), [docs/MULTIPLAYER_VERIFICATION.md](docs/MULTIPLAYER_VERIFICATION.md)).
  Сам релизный workflow эти две проверки не повторяет.
- Не увидено: мод на настоящей видеокарте и со звуком, крылья и призрачные блоки KAMI, другие моды, кроме EMI, JEI и Jade.

Что именно запускалось и было увидено по каждой части — в [docs/STATUS.ru.md](docs/STATUS.ru.md).

**Известная проблема.** С Thaumcraft 4 Reload до 0.1.0-alpha.24 включительно рецепты аддона с обсидиановой плиткой (в том числе
Осмотический стол зачарований) не принимают скрафченные плитки, и наполнение не начинается. Причина была в `ItemApi` самого Thaumcraft
и исправлена там коммитом [`299a9c0`](https://github.com/acak1221/Thaumcraft-1.21.1/commit/299a9c01); нужен первый релиз Thaumcraft 4
Reload после 0.1.0-alpha.24.

С Thaumcraft аддон разговаривает только через публичный `thaumcraft.api`: JUnit-тест `TinkererApiOnlyTest` роняет сборку, если
какой-нибудь исходник импортирует что-то ещё из Thaumcraft. До 2026-10-31 аддон писался внутри
[репозитория Thaumcraft 4 Reload](https://github.com/acak1221/Thaumcraft-1.21.1) (`NOTICE.md`, раздел «History»); там остаются расширения
API, которые нужны аддону, и руководства для авторов аддонов.
